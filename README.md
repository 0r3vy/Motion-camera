# Motion Camera (Pearl) - Fabric 1.21.11
Camera chỉ mượt sau khi bạn ném ender pearl (lúc bay + lúc dịch chuyển). Ngoài ra là vanilla.

Build:  .\gradlew.bat build   ->  build\libs\motion-camera-pearl-1.2.0.jar  (không dùng file -sources)
Cần: Fabric Loader 0.19.5+, Fabric API 0.141.6+1.21.11, Java 21.

Lệnh: /motioncamera toggle | status | reload | speed <0.02-1> | fpspeed <0.02-1> | duration <100-10000>
Config: .minecraft\config\motioncamera.json
